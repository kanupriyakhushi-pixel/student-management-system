# 🎓 Student Management System

A simple command-line based Student Management System built using Python.

This project allows users to manage student records using file handling, functions, lists, and basic error handling.

## 🚀 Features

✅ Add new students  
✅ Search students (case-insensitive search)  
✅ Remove students  
✅ Display all students  
✅ Save data permanently using file handling  
✅ Prevent duplicate entries  
✅ Input validation using try-except  

## 🛠️ Technologies Used

- File Handling
- Functions
- Lists
- Loops
- Exception Handling
- Git & GitHub

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/kanupriyakhushi-pixel/student-management-system.git
```

2. Open the project folder.

3. Run:

```bash
python code.py
```
